# XianJue (先觉)

Clipboard-driven proactive translation and vocabulary learning assistant.

## Overview

XianJue monitors your clipboard. When you copy foreign-language text, it
automatically pops a floating window with the translation -- zero clicks,
zero context switches. It supports cloud (DeepSeek, etc.) and local
(Ollama) translation engines, and includes a built-in vocabulary learning
system powered by SM-2 spaced repetition.

## Development

```bash
pip install -r requirements.txt
python -m src.xianjue.main
```
